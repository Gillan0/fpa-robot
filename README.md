# fpa-robot

Refactoring of an old university project to get back into Arduino coding.

## Original purpose

The original goal of that university project was to develop multiple features in 3 different teams.
Once all were finalized, we moved onto a scrum methodology and had to integrate each feature into a single project. 

These features were : 
- robot control,
- rfid tag read/write and display (lcd/neopixel)
- bluetooth remote messaging via a phone
